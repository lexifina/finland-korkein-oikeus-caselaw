# KKO 1865/1995

## Suomeksi

X oli antanut laskurahoitussopimukseen perustuvien, rahoittajan luotonsaajalta olevien saatavien vakuudeksi omavelkaisen takauksen. Valtiontakuukeskuksen maksettua myöntämänsä vientitakuun perusteella rahoittajan saatavan rahoittaja oli siirtänyt saatavansa vakuuksineen luotonsaajalta Valtiontakuukeskukselle. Kysymys siitä, oliko X maksuvelvollinen Valtiontakuukeskukselle sen esittämillä perusteilla.
