# KKO:1934-II-447

Määräalan ostaja vaati tilan pakkohuutokaupassa ostaneelta uudelta omistajalta korvausta siitä, ettei tämä ollut sallinut alueen erottamista vaan oli häätänyt hänet alueelta. Kanne hylättiin.
MM.
