# KKO:1975-II-93

Ään
Kun väitetyssä velaksiantotilaisuudessa mukana olleiksi ilmoitetuista henkilöistä kantaja ja hänen nimeämänsä todistaja olivat kertoneet kanteessa tarkoitetun velaksiannon, josta ei ollut tehty kirjallista todistetta, tapahtuneen, mutta vastaaja ja hänen nimeämänsä todistaja sen kieltäneet, eikä jutussa muuten esilletulleiden seikkojen perusteella voitu katsoa kummankaan asianosaisen kertomuksen tulleen näytetyksi vääräksi, velkomusta koskeneen kanteen katsottiin jääneen toteennäyttämättä.
MM-NS
